# Security Policy

## Reporting a vulnerability

Report suspected vulnerabilities through GitHub's private vulnerability
reporting for the `Vertiso/vertiso-authentication` repository.

Do not open a public issue for a suspected vulnerability. Do not include
credentials, tokens, exploits, or user data in a public issue or discussion.

## Supported versions

Before the first public release, Vertiso Authentication is under internal
adoption. Security fixes are applied to the current `main` branch. No released
version is supported yet.

After the first public release, the latest released version will receive
security fixes. Older release support will be documented here if Vertiso
adopts a broader support policy.
